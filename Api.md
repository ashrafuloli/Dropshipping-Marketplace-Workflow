# Required API Credentials

---

## 1. Meta Developer API

Used for accessing the Meta Ads Library and other Meta services.

Please provide:

- Meta Developer Account
- Meta App ID
- Meta App Secret
- Meta Access Token
- Business Verification (if required)
- Required permissions already approved (if applicable)

Reference:
https://developers.facebook.com/

---

## 2. TikTok Developer API

Used for accessing public TikTok content and business-related APIs (depending on your approved access level).

Please provide:

- TikTok Developer Account
- Client Key (Client ID)
- Client Secret
- Access Token (if available)
- Approved API scopes/permissions

Reference:
https://developers.tiktok.com/

---

## 3. Pinterest Developer API

Used for accessing Pinterest content and marketing data.

Please provide:

- Pinterest Developer Account
- App ID
- App Secret
- Access Token
- OAuth credentials (if applicable)

Reference:
https://developers.pinterest.com/

---

## 4. OpenAI API

Used for AI-powered features such as:

- Ad analysis
- Product analysis
- AI summaries
- Content generation
- Custom scoring explanations
- AI assistant/chat features

Please provide:

- OpenAI API Key

Reference:
https://platform.openai.com/

---

## Notes

- If you already have these credentials, please share them securely.
- If you don't have them yet, I can guide you through creating each account and generating the required API credentials.
- If additional third-party services are required during development, I'll let you know before implementation.
